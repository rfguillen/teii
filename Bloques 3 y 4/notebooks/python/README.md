# Fundamentos de Python

Notebook de ejercicios de programación de Python.

## Contenido

- [Fundamentos de Python - Ejercicios.ipynb](Fundamentos%20de%20Python%20-%20Ejercicios.ipynb): ejercicios.
- `palabras`: archivo de datos de apoyo.

## Uso

Abre el notebook en Jupyter con un kernel de Python y ejecuta las celdas en orden. Mantén `palabras` junto al notebook para que los ejercicios que leen ese archivo conserven su ruta de acceso.

Para instalar y abrir Jupyter en un entorno Python:

```bash
python -m pip install jupyterlab
python -m jupyterlab
```
