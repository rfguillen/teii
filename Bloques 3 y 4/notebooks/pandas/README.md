# Introducción a Pandas

Notebook de ejercicios para trabajar con datos en Python mediante Pandas. La carpeta reúne el cuaderno de la práctica y sus archivos adicionales.

## Contenido

- [Introduccion a Pandas - Ejercicios.ipynb](Introduccion%20a%20Pandas%20-%20Ejercicios.ipynb): notebook de trabajo.
- `data`: datos utilizados por los ejercicios.

## Uso

Desde esta carpeta, con un entorno Python:

```bash
python -m pip install jupyterlab pandas
python -m jupyterlab
```
