# Notebooks · Programación y análisis de datos

Ejercicios y ejemplos que permiten avanzar desde los fundamentos de Python hasta el análisis de datos y la visualización reactiva.

| Carpeta | Contenido | Entorno |
|---|---|---|
| [python](python/README.md) | Notebook de fundamentos y archivo de palabras de apoyo | Jupyter con kernel Python |
| [pandas](pandas/README.md) | Ejercicios de Pandas y datos de apoyo | Jupyter con Pandas |
| [marimo](marimo/README.md) | Consulta y visualización de datos meteorológicos de Murcia | Marimo, Pandas, Requests y Plotly |

## Uso

Consulta el README de cada carpeta. Los notebooks utilizan sus propios datos y deben abrirse manteniendo las rutas relativas de los archivos de apoyo.

Los archivos `.ipynb` contienen celdas que se ejecutan en Jupyter. El archivo de Marimo es un notebook reactivo guardado como código Python y se abre con Marimo.
