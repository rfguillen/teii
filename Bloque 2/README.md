# Bloque 2 · Virtualización y contenedores

Práctica sobre creación y administración de entornos virtualizados y despliegue de servicios mediante contenedores. La memoria documenta los ejercicios, su configuración y las comprobaciones realizadas.

## Áreas de trabajo

| Área | Herramientas | Enfoque |
|---|---|---|
| Máquinas virtuales | VirtualBox | Preparación y configuración de entornos virtualizados |
| Virtualización en Linux | KVM, libvirt y virsh | Administración de máquinas virtuales |
| Entornos reproducibles | Vagrant | Definición y gestión de entornos de trabajo |
| Contenedores | Docker | Creación y uso de contenedores |

## Documentación

[Memoria-Bloque2.pdf](Memoria-Bloque2.pdf) organiza la práctica en dos partes: virtualización con VirtualBox, KVM y Vagrant, y contenedores con Docker y Docker Compose.
